# homepage

Static homepage for [brettselby.xyz](https://brettselby.xyz), linking to
[pickems](https://pickems.brettselby.xyz) and [clr](https://clr.brettselby.xyz).

The whole site is `public/`: one `index.html` (styles inline) and `favicon.svg`. No build step.

```bash
npm run dev       # local preview on http://localhost:8788
npm run deploy    # publish to Cloudflare Pages
```

Deploy details, one-time setup and rollback: [docs/deploy.md](docs/deploy.md).
